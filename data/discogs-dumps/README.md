# Discogs dump files (not committed)

Put the official monthly Discogs data dumps here, e.g.

    discogs_20260901_artists.xml.gz
    discogs_20260901_labels.xml.gz
    discogs_20260901_masters.xml.gz
    discogs_20260901_releases.xml.gz
    discogs_20260901_CHECKSUM.txt

Everything in this folder except this README and `.gitkeep` is ignored by git.
See `docs/DISCOGS_IMPORT.md` for how to download, verify and import them.
